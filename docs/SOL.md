# SOL: установка и проверка на Windows 10/11 x64

Это локальное распознавание: WebView2 получает микрофон, AudioWorklet передаёт mono PCM16 через Tauri в Vosk. Аудио не пишется в файл и не отправляется в сеть. DLL/модель не поставляются в Git или установщике; до их установки голос не заработает. Нужен современный WebView2 с поддержкой getUserMedia/AudioWorklet. Текстовый router не заменяет распознавание.

## 1. Установка runtime и русской модели

1. Откройте **SOL → Локальные пакеты → Vosk runtime**. Кнопка скачивания открывает официальный [релиз Vosk 0.3.45](https://github.com/alphacep/vosk-api/releases/tag/v0.3.45) в браузере. Скачайте `vosk-win64-0.3.45.zip`, затем **Выбрать ZIP и установить**. Пакет проверяется до распаковки по закреплённому SHA-256:

   `f1dcc9cca460630f81ea8f71794f69c80bed6556d2a4e6237b5785e1d2dff34b`

   Эта сумма вычислена при разработке по архиву официального HTTPS-релиза, не является подписью издателя. Другие версии намеренно не принимаются. DLL загружается с абсолютного пути, зависимости — из её каталога и стандартных каталогов Windows; системный PATH не меняется.

2. Выберите **Русская модель small-ru-0.22**, откройте [официальный архив](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) (около 45 МБ). Используйте именно этот архив с корневым каталогом `vosk-model-small-ru-0.22`. Не берите случайные зеркала. Вставьте ожидаемый SHA-256 и выберите ZIP. Все обязательные файлы, CRC ZIP, размер, пути и SHA проверяются; ошибка не заменяет старый установленный пакет.

   В этой среде сайт модели недоступен (HTTP 403), поэтому закрепить независимо полученную сумму модели не удалось. Если издатель не предоставляет её отдельно, скачайте ZIP непосредственно по официальному HTTPS и получите сумму в PowerShell:

   ```powershell
   (Get-FileHash "$env:USERPROFILE\Downloads\vosk-model-small-ru-0.22.zip" -Algorithm SHA256).Hash
   ```

   Вставленная собственная сумма подтверждает неизменность выбранного файла относительно скачанной копии, **не подлинность издателя**. Источник в этом случае проверяется по официальному HTTPS-адресу самим пользователем. SHA из неизвестного сообщения/зеркала не делает пакет доверенным. Модель с автоматически проверяемым эталонным хешем остаётся задачей подготовки дистрибутива, не скрытым скачиванием.

3. Включите **Голосовое управление**, выберите микрофон (названия устройств появляются после разрешения), нажмите **Слушать SOL**. Разрешите WebView2 доступ. В Windows при отказе проверьте «Конфиденциальность → Микрофон → Разрешить классическим приложениям доступ».
4. Произнесите «Сол, открой Стим» или «Сол, включи работу», сделайте паузу. При обычном режиме Vosk завершает одну фразу, микрофон освобождается, команда выполняется существующими службами. Кнопка остановки отменяет захват без выполнения незавершённой фразы.

Пакеты хранятся в локальном каталоге данных Tauri `com.assistent1.desktop/sol` (обычно `%LOCALAPPDATA%\com.assistent1.desktop\sol`). Там `runtime/`, `model/`, `audio/` и их `installed.sha256`; пользовательские режимы/библиотека остаются в прежнем WebView-хранилище v4. Переустановка пакета не меняет их.

## 2. Команды и постоянное прослушивание

Примеры: «Сол, привет», «открой Steam/Дискорд/YouTube», «включи игру/работу/отдых», «включи режим Монтаж видео», «покажи команды», «Сол, стоп». Имена читаются из текущих настроек; сохранённые команды поддерживаются по названию/фразе. Неоднозначные и неизвестные команды ничего не запускают. Произвольных shell-команд и голосового принудительного закрытия нет.

Опция активации «Сол» выключена по умолчанию. Её включение только разрешает непрерывный захват **после нажатия кнопки**; после перезапуска приложение само микрофон не включает. Используется тот же Vosk, отдельный wake word detector не заявлен. Фразы без префикса игнорируются; случайное распознавание всё равно возможно, поэтому закрытие всегда требует диалога. На паузах Vosk может обрабатывать обычную речь — нагрузку/точность нужно оценить на вашем ПК. Во время обработки команды/звучания ответов вход не подаётся на распознавание, чтобы не запустить ответом самого себя.

**Остановить**, «Сол, стоп», отключение управления, закрытие главного окна и выход освобождают микрофон. В главном окне и палитре виден активный захват; в палитре есть «Стоп». Переключение страниц не выключает явно разрешённое прослушивание. Звук выключается независимо; изменение микрофона/режима захвата останавливает текущую сессию.

## 3. Собственный пакет голосовых ответов

В репозитории **нет готовых записей**. Поддержка пакета реализована, реальное звучание без записей не заявляется. Законный вариант — записать собственный голос либо заказать диктору запись с письменным разрешением на коммерческое распространение. Не используйте чужие/знаменитые голоса и синтез с неясными правами на результат.

Сохраните реальные короткие записи WAV PCM16, mono/stereo, 8–48 kHz, каждый до 4 МБ. Сделайте ZIP с каталогом `sol-voice/`:

| Файл | Текст |
| --- | --- |
| hello.wav | Привет. SOL на связи |
| listening.wav | Слушаю |
| opening.wav | Открываю |
| mode.wav | Запускаю режим |
| done.wav | Готово |
| errors.wav | Некоторые действия не выполнены |
| unknown.wav | Не понял команду |
| cancelled.wav | Отменено |
| goodbye.wav | До встречи |

Добавьте `sol-voice/manifest.json`, например `{"author":"Ваше имя","license":"Собственная запись; разрешено коммерческое использование и распространение"}`. Метаданные фиксируют ваше заявление, приложение не удостоверяет юридические права. Для сторонней записи приложите разрешение/лицензию в ZIP. Не заменяйте WAV пустыми файлами.

Упакуйте `sol-voice` в ZIP, вычислите SHA-256 командой Get-FileHash, выберите **Собственный аудиопакет**, вставьте сумму и установите ZIP. Включите ответы, нажмите **Проверить голос**. Воспроизведение локальное и асинхронное; краткий режим пропускает вступительные сообщения. Фраза «Слушаю» намеренно не воспроизводится в активный микрофон перед началом PTT, чтобы не терять начало команды.

## 4. Переключение режимов

Первый запуск после открытия приложения не закрывает ничего. Далее прошлый режим служит источником EXE, но работающие процессы/доступные окна проверяются заново. Общие ID/файлы нового режима, браузеры, сайты и папки не предлагаются к закрытию. Неидентифицированные фоновые/helper-процессы остаются нетронутыми.

Все варианты по умолчанию «Оставить». «Отмена» не закрывает ничего и не запускает новый режим. «Оставить всё» запускает следующий режим; «Закрыть выбранные» перепроверяет PID, время создания процесса, EXE и HWND, отправляет только WM_CLOSE. Ни TerminateProcess, ни taskkill нет. При диалоге сохранения/таймауте или сохранившемся фоновом процессе показана ошибка, процесс не уничтожается, новый режим запускается после принятого решения. Ошибки закрытия остаются видны отдельно от результатов запуска. Исполнитель/защита от повторов общие у главного окна, палитры и SOL.

## 5. Лицензии и границы проверки

Vosk API 0.3.45 — Apache-2.0: проверен [официальный COPYING](https://github.com/alphacep/vosk-api/blob/v0.3.45/COPYING), копия в `docs/licenses/VOSK-APACHE-2.0.txt`. Apache-2.0 допускает коммерческое применение с соблюдением условий. Runtime ZIP содержит также DLL GCC/pthreads: при будущем включении их в установщик отдельно проверьте и приложите лицензии/уведомления этих компонентов. Сейчас официальный runtime устанавливается пользователем отдельно, не перераспространяется проектом.

Для `vosk-model-small-ru-0.22` в [официальном каталоге моделей](https://alphacephei.com/vosk/models) указана Apache-2.0; сайт из среды разработки отвечает 403, метаданные конкретного скачиваемого пакета здесь независимо не перепроверены. Перед коммерческой поставкой модели нужно подтвердить лицензию конкретного архива и сохранить уведомления. Модель в этот дистрибутив не включается. Готовый коммерческий голосовой комплект не объявлен выпущенным.

Локальные автоматические тесты проверяют router, PCM, переключение, настройки и безопасную установку ZIP. Windows EXE тестов компилируются, но Linux не проверяет настоящий Windows-микрофон/распознавание/воспроизведение. На Windows выполните:

```powershell
cargo test --locked --manifest-path tests/rust-validation/Cargo.toml
```

Затем вручную проверьте отказ/отсутствие микрофона, отмену разрешения, стоп во время загрузки модели, русские фразы/неизвестные/двойные имена, пользовательский режим, независимое отключение звука, реальный WAV, непрерывное прослушивание/остановку/нагрузку, переключение с отменой/общим приложением/диалогом сохранения, палитру и трей. Windows CI запускается PR автоматически; ручной dispatch не нужен.
