# SOL: один установщик для Windows 10/11 x64

## Для пользователя

Тестовая версия 0.1.2: полная сборка — **Assistent1.exe**. Она содержит Vosk 0.3.45, русскую модель small-ru-0.22, лицензионные уведомления и offline-установщик WebView2 для Windows без этого компонента. Загрузка модели/DLL, вычисление SHA и настройка путей покупателю не нужны. NSIS устанавливает приложение для текущего пользователя; голос работает без интернета после установки.

Откройте **SOL**, нажмите **Слушать SOL**, разрешите микрофон Windows/WebView2. Кнопка явно включает голосовое управление; никакого захвата до нажатия нет. Скажите «Сол, включи игровой режим» и сделайте паузу. В обычном режиме обрабатывается одна фраза, затем микрофон освобождается. **Остановить**, «Сол, стоп», выключение управления, крестик главного окна и выход прекращают захват. В палитре есть состояние SOL и кнопка остановки.

Опциональное непрерывное прослушивание с префиксом «Сол» выключено по умолчанию. Даже сохранённая опция не включает микрофон сама после перезапуска: нужна кнопка. Фразы без префикса игнорируются. Во время ответа/обработки команды звук не подаётся распознавателю. Это тот же Vosk, а не отдельный малоресурсный wake detector; нагрузка/точность требуют проверки на вашем ПК.

Команды: «Сол, привет», «открой Steam/Стим/Дискорд/YouTube», «включи игру/работу/отдых», «включи режим [собственное название]», «покажи команды», «стоп». Имена берутся из сохранённых данных. Неизвестные и неоднозначные фразы ничего не выполняют. Приложения по-прежнему нужно настроить в библиотеке: SOL не предполагает, что Steam/Discord установлены.

Если компоненты отсутствуют/повреждены, показана ошибка с предложением переустановить **полную** версию. Переустановка не должна удалять пользовательские настройки. Не устанавливайте старую сборку без SOL. Ресурсы находятся рядом с установленным EXE в `sol/runtime`, `sol/model`, `sol/licenses`; их перечень и SHA привязаны к установленной версии приложения. Прежние пользовательские данные остаются в прежнем WebView-хранилище v4. Старые вручную установленные пакеты не удаляются, но для Runtime/модели используется проверенный комплект установщика.

## Переключение режимов

Исполнитель один у главного окна, палитры и голоса. Прошлый режим в памяти — только источник EXE: фактическое состояние проверяется заново. Общие стабильные ID/нормализованные пути/подтверждённые файловые aliases исключаются из диалога. Браузер не закрывается из-за вкладки. Первый запуск после открытия приложения не предлагает закрытие.

При переходе проверка уже работающих программ обязательна для этого запуска (сохранённые настройки библиотеки не переписываются). Совпадающий работающий EXE не запускается и не сворачивается повторно; новые EXE запускаются при подтверждённом отсутствии. При неопределённой идентичности/фоновом процессе нет случайного повторного запуска — показана диагностика. Сайты по-прежнему являются отдельными запросами открытия.

Для остальных приложений по умолчанию «Оставить». «Отмена» ничего не закрывает и не запускает следующий режим. «Оставить всё» продолжает. Выбранные окна перепроверяются по EXE, PID, времени создания процесса и владельцу HWND, затем получают WM_CLOSE. Неопознанные процессы и чужие окна не закрываются. Диалог сохранения, фоновый остаток или таймаут дают ошибку без kill; ошибки входят в сохранённый итог режима даже при успешном запуске новых действий.

## Голосовые ответы

Реальных записей пока **нет**: звук не имитируется. Поддерживаются асинхронные WAV PCM16, независимое выключение ответов, громкость, краткий режим и «Проверить голос». Пока пакет отсутствует, это честно показано. Микрофон от выключения ответов не отключается.

Законный способ подготовить пакет — записать собственный голос либо получить письменные права от диктора. Не используйте чужие голоса или синтез с неясными правами. Каталог `sol-voice/` содержит реальные WAV mono/stereo 8–48 kHz, каждый до 4 МБ:

| Файл | Фраза |
| --- | --- |
| hello.wav | Привет. SOL на связи |
| listening.wav | Слушаю |
| opening.wav | Открываю |
| mode.wav | Запускаю режим |
| done.wav | Готово |
| errors.wav | Некоторые действия не выполнены |
| unknown.wav | Не понял команду |
| cancelled.wav | Отменено |
| goodbye.wav | До встречи |

В `manifest.json` укажите `author`, `license`, а для упаковки разработчиком — `commercialUseApproved: true` после проверки прав. Само поле не является юридическим доказательством. Приложите `LICENSE.txt`/разрешение. Фразу «Слушаю» нельзя подавать в уже активный микрофон перед PTT, чтобы не потерять начало команды.

Свой дополнительный ZIP можно установить в скрытом разделе **Собственный пакет голосовых ответов**, указав его контрольную сумму. Это авторский пакет, не обязательная настройка для покупателей. Проверенные записи можно встроить в тот же EXE через `--audio-directory`; тогда отдельный ZIP не нужен. Локальный авторский пакет хранится в AppLocalData/sol/audio и переживает переустановку.

## Сборка разработчиком и GitHub Actions

Крупные архивы/распакованные ресурсы не входят в Git. Python 3.11+:

```powershell
python scripts/prepare_sol.py
npm ci
npm run tauri build -- --config src-tauri/tauri.bundle.conf.json --target x86_64-pc-windows-msvc --bundles nsis --ci -- --locked
```

Скрипт получает только официальные HTTPS-источники. Проверяет версию, размер (Runtime ровно 14 882 445 байт; модель ограничена 40–55 МБ, HTTP Content-Length сверяется, точные байты записываются в manifest), закреплённую SHA-256, CRC/размеры ZIP, безопасные пути и обязательные файлы. Эталонный хеш фиксирует точное содержимое модели, независимо от имени ZIP `(1)`:

- Runtime: `f1dcc9cca460630f81ea8f71794f69c80bed6556d2a4e6237b5785e1d2dff34b` — официальный GitHub-релиз v0.3.45.
- Модель: `961d5ff98a17f4aa6de69864d0aa71fa5bac682301d2b5d17a3f24c5c99a46d4` — официальный alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip, ожидаемый хеш предоставлен пользователем.

Хеш не заменяет происхождение: источник модели и Apache-2.0 проверяются по конкретной строке официального каталога, его копия сохраняется с лицензиями. Недоступный источник/неизвестная лицензия/неверный хеш останавливают сборку. Для локальной офлайн-сборки разработчик может передать `--runtime-archive`, `--model-archive`, `--catalog` (сохранённая копия официальной страницы). Для авторских записей — `--audio-directory path/to/sol-voice`.

Ресурсы подготавливаются в игнорируемый `src-tauri/resources/sol`. SHA manifest встраивается в приложение и отдельный проверяющий EXE при компиляции; произвольный самосогласованный manifest не принимается. Проверяются и распакованные файлы, а не только ZIP. Параметр `tauri.bundle.conf.json` обязателен для полноценного установщика. Для dev после подготовки ресурсов подходит `npm run tauri dev`; недоукомплектованная dev-среда показывает отсутствие SOL, не имитирует его.

Windows CI автоматически работает по push в `codex/**` и PR к main/предыдущей SOL-ветке. Собирает официальный Tauri NSIS, устанавливает его без UI во временный каталог, дважды проверяет DLL/модель/уведомления/manifest, реально загружает Vosk+русскую модель и подаёт PCM тишины. Повторная установка проверяет сохранность контрольного файла в AppLocalData. Это **не проверка микрофона и не доказательство распознавания слов**. Прежние native launch/tray tests остаются включены. После успешных проверок artifact **Assistent1-windows-x64-SOL** содержит один **Assistent1.exe**. Архив artifact GitHub — лишь транспортная оболочка; покупателю не нужны другие компоненты рядом с EXE. WebView2 берётся официальным Tauri offline-installer механизмом Microsoft; его версия управляется этим механизмом, побитовая воспроизводимость всего EXE не заявляется.

## Лицензии, выполненные проверки и ограничения

См. `SOL-THIRD-PARTY.md` и `licenses/`. Проверены upstream тексты Vosk, GCC Runtime Exception/GPL, winpthread 8, Kaldi/OpenFst/OpenBLAS/CLAPACK; точная бинарная provenance/source-conveyance проверка всех зависимостей и условия Microsoft ещё требуют выпускающего аудита. Коммерческая готовность не заявляется (`commercialAuditComplete: false`). Для модели CI должен получить независимое подтверждение лицензии из официального каталога.

В этой облачной среде предоставленный Runtime получен, совпал с официальным хешем и прошёл CRC. Вложение модели превышает лимит переноса инструмента 32 МиБ; официальный сайт отвечает 403, поэтому архив модели здесь не получен и полный installer здесь не проверен. Это объективное ограничение, а не успешная упаковка. Windows CI должен выполнить описанные настоящие проверки; статус сообщается отдельно после публикации, если доступен API.

Локально проверяются TypeScript/router/PCM/сохранение/отмена/общие приложения, Rust inventory/hash/ZIP и Windows GNU compilation. На ПК пользователя остаются настоящий микрофон, разрешение/отказ/отсутствие устройства, русские фразы, остановка/освобождение захвата, непрерывное прослушивание/нагрузка, реальное WAV-звучание после появления записей, переход Игра → Работа с общими Discord/Telegram, несохранённые документы, палитра/трей/single-instance и повторный запуск без сети. Успешное завершение модульных тестов не означает прохождения этих аппаратных сценариев.
